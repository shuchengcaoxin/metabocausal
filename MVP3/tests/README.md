# Human-GEM tests

ambiguity, missing/corrupt models, hub policy, compartments, reaction direction,
AND/OR GPR rules, batch reuse and source-backed glycine/isoleucine/TMAO/citrate cases.
`tests/test_mvp3_integration.py` covers the shared ledger, pipeline, renderer and
bounded 1E handoff. The final expanded-MVP2 and Slack acceptance remains Gate 2 work.
