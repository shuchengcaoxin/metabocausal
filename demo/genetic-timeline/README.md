# Genetic Timeline Demo

This folder documents a saved timeline-style output used in the MetaboCausal presentation.

The timeline image is stored at:

`../../docs/assets/cetp-timeline.png`

It illustrates one design principle: dated genetic, preclinical and clinical evidence should be kept separate.

The example is not the whole product. It is a public-safe demonstration of how MetaboCausal can make evidence history easier to inspect.
