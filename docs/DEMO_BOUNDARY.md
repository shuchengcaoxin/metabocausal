# Demo Boundary

This repository is a product and demo package.

It is meant to help readers understand MetaboCausal without turning the demo into a full reproducible research pipeline.

## Included

- project overview
- product design notes
- static demo HTML
- screenshots
- presentation deck

## Excluded

- source data
- team logs
- raw search exports
- detailed literature screening instructions
- API credentials
- Slack deployment credentials
- repository history
- unpublished intermediate files

## Why the boundary matters

MetaboCausal is about evidence tracing. Some source records and development notes are useful for review, but they are not needed for a concise demo package.

This repository should explain the project and demonstrate the interface. It does not need to publish data-management details that would distract from the product story.
