# Public Boundary

This repository is a public product and demo package.

It is meant to help readers understand MetaboCausal without exposing private development materials.

## Included

- public overview
- product design notes
- static demo HTML
- screenshots
- presentation deck

## Excluded

- private source data
- private team logs
- raw literature search exports
- detailed literature screening instructions
- API credentials
- Slack deployment credentials
- private repository history
- unpublished intermediate files

## Why the boundary matters

MetaboCausal is about evidence tracing. Some evidence sources and development records are useful for private review, but they are not appropriate for a public hackathon-facing repository.

The public repository should explain the project and demonstrate the interface. It should not publish internal data-management details that could confuse readers or expose work not intended for release.
