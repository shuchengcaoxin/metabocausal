# Search runs

The discovery task writes each run to its own folder: exact queries, service responses, deduplicated candidate IDs, follow-up reasons, request/round budgets and stopping status.

The first live Europe PMC-only agentic example is [`20260912_europepmc_agentic_glycine_cad/`](20260912_europepmc_agentic_glycine_cad/). It demonstrates broad metabolome-wide discovery, inspection-driven pair-specific follow-up, and a deliberate challenge search. Semantic Scholar was not searched; its workstream should deduplicate against the identifiers in that run before reporting new discoveries.
